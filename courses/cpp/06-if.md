# Making choices

`if` runs some code only when something is true. `else` runs when it isn't:

```cpp
#include <iostream>
using namespace std;

int main() {
    int age;
    cin >> age;

    if (age >= 13) {
        cout << "You can make an account.\n";
    } else {
        cout << "Ask a grown-up first.\n";
    }
}
```

```input
15
```

```output
You can make an account.
```

Change the input to `9` and run it again.

The test goes in brackets after `if`. You can compare with:

- `==` is equal to (two `=`, because one `=` puts a value in a variable)
- `!=` is not equal to
- `<` and `>` are less than and more than
- `<=` and `>=` are less than or equal, more than or equal

## Your turn

Read a whole number and print `even` if it is even, or `odd` if it isn't.

Hint: a number is even when dividing it by 2 leaves nothing over. Remember `%` from the maths lesson?

```starter
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    cout << "even\n";
}
```

```solution
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    if (n % 2 == 0) {
        cout << "even\n";
    } else {
        cout << "odd\n";
    }
}
```

```test
input:
4
output:
even
```

```test
input:
7
output:
odd
```

```test
input:
0
output:
even
```
