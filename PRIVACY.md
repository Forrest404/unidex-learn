# Privacy

learn.unidex.shop has no accounts, no cookies, no analytics and no ads.

**Your code.** When you press Run or Check, the code in the editor, and the input box if there is one, is sent to [Compiler Explorer](https://godbolt.org) to be built and run. If Compiler Explorer is busy or can't be reached, it goes to [Wandbox](https://wandbox.org) instead. Each service has its own privacy policy: [Compiler Explorer](https://github.com/compiler-explorer/compiler-explorer/blob/main/docs/Privacy.md), [Wandbox](https://github.com/melpon/wandbox). Nothing else is sent anywhere.

**This browser.** The code you type in each lesson and which lessons you've finished are kept in this browser's local storage, so they're still there next time. They never leave your device. Clearing your browser's site data removes them.

**The site.** It's hosted on GitHub Pages, which keeps server logs as described in [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
